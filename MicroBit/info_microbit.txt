== LENGUAJE ELEGIDO: CODAL C++ ✅ ==
Decidimos programar la micro:bit en CODAL C++ (no MicroPython ni
MakeCode) por maximo rendimiento:
- 60 FPS de refresco por HARDWARE (PPI + GPIOTE) -> animaciones fluidas
- Las caras/imagenes viven en FLASH (memoria permanente), casi no
  tocan la RAM -> caben MUCHAS expresiones sin preocuparse
- setBrightness() SI existe (el MicroPython de esta build no lo traia)
- Flash usado por el programa actual: ~28% (queda muchisimo espacio)

== PROGRAMA ACTUAL (CODAL C++) ==
Fuente versionada: Codigo/Principal.cpp + Codigo/Animaciones + Codigo/Funciones
Build local:       Referencias/codal-microbit-v2-samples/source/main.cpp
- 8 emociones animadas + transiciones de 60 FPS
- 10 patrones de loading, incluyendo uno que usa el accelerometro y otro la luz
- Receptor serial y BLE: la IA manda los mismos comandos por USB o Bluetooth
- Replica del frame LED para la web
- Escucha manual con A/B y FFT real del microfono para las animaciones

Comandos serial (linea terminada en \n):
  HAPPY/SAD/ANGRY/SURPRISED/NEUTRAL/FASTIDIO/MIEDO/CANSADO -> emoción
  TALK/LOADING/LOAD0..LOAD9/STOP                           ->talk/loading/stop
  SENSOR:TEMP   -> TEMP:<grados Celsius>
  SENSOR:LUZ    -> LUZ:<0..255>
  SENSOR:BOTON  -> BOTON:<A>:<B>
  SENSOR:ACCEL  -> ACCEL:<x>:<y>:<z>:<pitch>:<roll>
  SENSOR:MIC    -> MIC:<nivel>:<b0>:<b1>:<b2>:<b3>:<b4>:<ventanas>
  SENSOR:BAT    -> BAT:<bateria_mV>:<entrada_mV>:<fuente>
  SENSOR:GESTO  -> GESTO:<codigo>:<magnitud_mili-g>
  SENSOR:BRUJULA -> BRUJULA:<rumbo>:<campo>:<calibrada>
  SENSOR:TOQUE  -> TOUCH:<presionado>:<lectura capacitiva>
  CALIBRAR:BRUJULA -> calibracion UX manual de CODAL (puede tardar ~32 s)
  ESCUCHAR     -> espera manual: primer A graba, segundo A envia, B cancela
Respuesta: ACK:<COMANDO> y, para sensores, la linea de lectura correspondiente.

== COMPILAR Y FLASHEAR ==
1. Editar Codigo/Principal.cpp, Codigo/Animaciones/ o Codigo/Funciones/
2. Sincronizar todo Codigo/ al source local y regenerar el build:
   rsync -a --delete Codigo/ Referencias/codal-microbit-v2-samples/source/
   rm -f Referencias/codal-microbit-v2-samples/source/Principal.cpp
   cp Codigo/Principal.cpp Referencias/codal-microbit-v2-samples/source/main.cpp
   cd Referencias/codal-microbit-v2-samples
   rm -rf build
   python3 build.py
3. Copiar MICROBIT.hex a la unidad MICROBIT (se flashea solo)
   cp MICROBIT.hex /media/zkazen/MICROBIT/MICROBIT.HEX

== COMUNICARSE CON LA MICRO:BIT DESDE PYTHON (PC) ==
import serial, time
ser = serial.Serial('/dev/ttyACM0', 115200, timeout=2)
ser.write(b'HAPPY\n')     # manda la emocion
resp = ser.read(200)      # lee el ACK
ser.close()
