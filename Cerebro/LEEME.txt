QUE ES ESTA CARPETA
--------------------------------------------------------------------------------
  MicroBit/  = LA CARA  (las expresiones fisicas: emociones, loading, TALK)
  Cerebro/   = EL CEREBRO (el chat, la IA, la personalidad, la pantalla)

  El micro:bit ES la expresion de Kira. Esta carpeta es la mente:
  recibe lo que la gente escribe, Kira (DeepSeek) piensa, decide que
  emocion sentir (JSON mode) y le manda el comando al micro:bit por
  serial (SAD, HAPPY, TALK, LOADING...).

ARQUITECTURA DEL FLUJO (lo que vamos a construir aca):
--------------------------------------------------------------------------------
  Persona en la feria
    -> escribe en la interfaz web (chat en el navegador)
    -> kira_server.py (servidor local en localhost:8000)
       -> llama a DeepSeek (deepseek-v4-flash, JSON mode + temperatura)
       -> recibe { emotion, message }
       -> emotion -> serial al micro:bit (pyserial): "ANGRY\n"  -> anima
       -> message -> Fish Audio TTS (s2.1-pro-free) -> suena la VOZ
    La interfaz es web (HTML/CSS/JS servida por el servidor local):
    se puede hacer MUY linda y el navegador ya esta en cualquier Windows.
